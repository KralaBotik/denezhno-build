# Денежно — сборка

Исходники мобильного приложения личных финансов «Денежно» (Flutter, iOS) для
сборки и тестов в GitHub Actions.

- Linux-проверки (анализ, unit/widget-тесты) запускаются на каждый push.
- Сборка iOS (неподписанный IPA) и тест на iOS Simulator — только вручную:
  Actions → CI → Run workflow.

Разработка ведётся в отдельном репозитории; сюда выгружается снимок
исходников без истории. Pull request'ы не принимаются.
